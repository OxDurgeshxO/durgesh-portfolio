# Contributing to durgesh-portfolio

Thank you for your interest in contributing!

## Setup

```bash
# Clone the repo
git clone https://github.com/OxDurgeshxO/durgesh-portfolio.git
cd durgesh-portfolio

# Install dependencies
pnpm install

# Run type check
pnpm typecheck

# Build
pnpm build
```

## Guidelines

- Use TypeScript for all new code
- Run `pnpm check` before submitting a PR
- Keep PRs focused — one feature or fix per PR
- Write meaningful commit messages

## Reporting Issues

Open an issue at: https://github.com/OxDurgeshxO/durgesh-portfolio/issues
