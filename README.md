---

## ✨ Features

- ⚡ **Lightning-fast** — Optimized build pipeline with pnpm workspaces
- 🎨 **Modern UI** — Clean, responsive design with Tailwind CSS
- 🧩 **Modular Architecture** — Frontend/backend split via monorepo structure
- 🔒 **Type-safe** — Full TypeScript coverage across the stack
- 📦 **Caffeine-powered** — Built on the `@caffeineai/core-infrastructure` framework

## 🚀 Getting Started

### Prerequisites

- Node.js ≥ 16.0.0
- pnpm ≥ 7.0.0 (`npm install -g pnpm`)

### Installation

```bash
# Clone the repository
git clone https://github.com/OxDurgeshxO/durgesh-portfolio.git
cd durgesh-portfolio

# Install dependencies
pnpm install

# Start development server
pnpm -r run dev
```

### Build

```bash
pnpm build
```

### Type Check

```bash
pnpm typecheck
```
